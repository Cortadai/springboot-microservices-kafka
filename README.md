Este repositorio es un proyecto de demostración de **arquitectura de microservicios basada en eventos** utilizando Spring Boot y Apache Kafka. Implementa un sistema de procesamiento de órdenes distribuido compuesto por cuatro módulos: **order-service** (microservicio productor que expone una API REST en `/api/v1/orders` para recibir órdenes, generar un UUID, crear eventos con estado "PENDING" y publicarlos en un topic de Kafka), **email-service** (consumidor que escucha los eventos de órdenes para enviar notificaciones por correo electrónico a los clientes), **stock-service** (consumidor que procesa los eventos de órdenes para actualizar el inventario y persistir la información en base de datos), y **base-domain** (módulo compartido que contiene los DTOs comunes como `OrderDto` y `OrderEventDto` utilizados por todos los servicios). La arquitectura demuestra el patrón de comunicación asíncrona entre microservicios desacoplados mediante mensajería con Kafka, permitiendo que múltiples servicios reaccionen de forma independiente a un mismo evento de negocio.
